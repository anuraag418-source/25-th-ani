# The 25th Anniversary: Mr. Ajay Kumar (DC) & Mrs. Shallu

Static website (HTML + CSS + a tiny bit of JavaScript). No build step, no paid assets.

## Files
- `index.html`  page content
- `style.css`   all styling
- `script.js`   soft scroll fade-in (page works without it)
- `audio/`      put your song here as **song.mp3** (see below)
- `images/`     your four photos (resized for fast loading) and the mandala ornament

## Publish free with GitHub Pages
1. Create a free account at https://github.com and click **New repository**.
2. Name it (for example `the-25th-anniversary`), set it to **Public**, and click **Create repository**.
3. Click **uploading an existing file**, drag in everything from this folder
   (`index.html`, `style.css`, `script.js`, and the whole `images` folder), then click **Commit changes**.
   `index.html` must be at the top level of the repository, not inside another folder.
4. Go to **Settings → Pages**. Under **Build and deployment**, set Source to
   **Deploy from a branch**, Branch to **main**, folder to **/ (root)**, then click **Save**.
5. Wait 1–2 minutes. Your link appears at the top of that page:
   `https://YOUR-USERNAME.github.io/the-25th-anniversary/`
6. Share that link with guests (WhatsApp, text, email).

## Editing later
Open a file in your repository, click the pencil icon, edit, and commit. The site updates in about a minute.
To swap a photo, upload a new image with the same file name into `images/`.

## Music
The song is `audio/song.mp3` (already trimmed so it starts at the 0:46 mark, with a soft fade-in) and plays when the website opens.
Browsers do not allow sound before a visitor interacts, so if autoplay is blocked the song begins on the guest's first tap, click or key press.
To change the song, replace `audio/song.mp3` with another MP3 of the same name.
